# 隐私说明

这个项目的核心承诺很简单：

> **你的身体数据只存在你自己的浏览器里，不会上传到任何地方。**

下面是具体怎么做到的，以及你可以怎么自己验证。

---

## 数据存在哪

**唯一位置**：浏览器 `localStorage` 里的一个 key —— `dachu.v1`。

```js
// public/js/data.js
var KEY = "dachu.v1";
```

没有账号、没有数据库、没有云同步、没有登录。

## 代码里没有任何"外发"通道

全部计算都在浏览器里完成：

- 单位换算（厘米/英寸/市寸、公斤/斤）
- 松量推算（后裆长、大腿围该找多少）
- 尺寸表解析（正则 + 表格结构分析）
- 尺码匹配打分

代码里**没有**：
- `fetch()` 或 `XMLHttpRequest` 向外发送你的数据
- `navigator.sendBeacon`
- 任何统计 / 埋点 / 分析脚本
- 任何第三方 CDN 依赖（所有 JS 都在本地）

唯一用到 `fetch()` 的地方是「批量比对」页里**抓取你粘贴的商品链接**——
发出去的是商品页 URL，回来的是商品页 HTML，你的身体数据不参与这个请求。

## GitHub 上有什么、没有什么

| 上传到 GitHub 的 | 不会上传的 |
| --- | --- |
| 代码（HTML/CSS/JS） | 你的身体测量数据 |
| 图标、文档 | 你导出的备份文件 |
| 测试用例（里面的数字是测试夹具，不是你的） | 分享链接里的数据 |

仓库里 `.gitignore` 排除了：
- `node_modules/`（依赖）
- `shots/`（截图产物）
- `.env` / `.local`（本地配置）

**注意**：如果你哪天手动把导出的 `dachu-backup-*.json` 拖进了仓库目录，
它不会被自动忽略。上传前请检查 `git status`。

## 什么时候数据会离开设备

只有**你主动**做这两件事时：

1. **点「复制分享链接」** —— 数据被压缩后放进 URL 的 `#` 后面
2. **点「导出文件」** —— 生成一个 JSON 文件给你自己保存

这两种都是你手动触发的。分享链接**等同于你的身体数据**，
别发到公开群、别贴到公开 issue。

## 你可以自己验证

### 方法一：断网测试

1. 打开页面，填几个数
2. 手机开飞行模式 / 电脑断网
3. 刷新页面

所有功能应该照常工作。**一个需要联网上传的工具，断网就会坏。**

### 方法二：看浏览器开发者工具

1. 按 `F12` 打开 DevTools
2. 切到 **Network** 标签
3. 正常操作一遍（填数据、比对、切换单位）

你应该只看到本地文件的加载请求，**没有任何发往外部域名的请求**。

### 方法三：搜代码

```bash
git grep -n "fetch\|XMLHttpRequest\|sendBeacon" public/
```

只会命中「批量比对」里抓商品页的那一处。

## 一个必须说清楚的取舍

**本地存储 ≠ 云备份。** 好处是隐私，代价是：

- 清浏览器数据会丢
- 换手机不会自动同步
- 无痕模式关掉就没了

所以工具里同时做了「导出文件」和「分享链接」两条备份路径。
**录完数据后请导出一次**，这是唯一能防丢的办法。

如果你的需求是"多设备自动同步"，那就必须有服务器和账号——
这和"数据只存在本地"是互斥的，需要你自己权衡。
