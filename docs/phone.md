# 手机上怎么用

> 短答：**不需要 APK，也不需要 AI。**它就是一个网页；用 HTTPS 打开后可以「添加到主屏幕」，
> 表现和 App 一样，而且能离线用。

---

## 先说结论：三种方式怎么选

| 方式 | 需要什么 | 能离线 | 能"加桌面" | 建议 |
| --- | --- | --- | --- | --- |
| **GitHub Pages**（推荐） | 上传一次仓库 | ✅ | ✅ | 日常就用这个 |
| 局域网临时访问 | 电脑开着 + 同一 Wi-Fi | ❌ | ❌ | 只想在手机上试一下 |
| 打包成 APK | Android SDK + 签名 | ✅ | ✅ | 不推荐，维护成本高 |

**为什么推荐 PWA 而不是 APK：**

- 不用装、不用更新、不用管签名
- 改一行代码，你手机刷新一下就生效
- 数据存在浏览器里，和网页版完全一致
- APK 需要你自己搭 Android 构建环境，打包出来的还是个"套壳浏览器"，
  功能一模一样但每次更新都要重新打包

## 方式一：PWA（推荐）

### 1. 部署到 GitHub Pages

按 [deploy.md](deploy.md) 上传，然后在仓库 `Settings → Pages` 里
Source 选 **GitHub Actions**。

等一两分钟，你会得到：

```
https://<你的用户名>.github.io/dachu-fitcheck/
```

**必须是 https** —— Service Worker 和「添加到主屏幕」只在 HTTPS 下工作
（`localhost` 除外）。

### 2. 手机打开这个地址

用 Safari（iPhone）或 Chrome（Android）。

### 3. 添加到主屏幕

- **iPhone Safari**：底部「分享」→ 向下滑 → **添加到主屏幕**
- **Android Chrome**：右上角「⋮」→ **添加到主屏幕 / 安装应用**

加完之后桌面上会有一个图标，点开是全屏的，没有地址栏，和 App 一样。

### 4. 验证离线可用

打开一次之后，把手机**开飞行模式**，再点桌面图标——
应该还能正常打开（因为 Service Worker 缓存了所有文件）。

## 方式二：局域网临时访问（不部署也能在手机上试）

适合"我就想现在看看手机上长什么样"。

1. 电脑和手机连**同一个 Wi-Fi**
2. 在电脑上运行：

```powershell
cd "大码尺码助手"
powershell -ExecutionPolicy Bypass -File scripts/serve-lan.ps1
```

3. 脚本会打印一个地址，比如：

```
http://192.168.0.60:4173/
```

4. 手机浏览器打开这个地址
5. 按 `Ctrl+C` 停止

**限制**：因为是 `http://` 而不是 `https://`，浏览器不会启用 Service Worker，
所以这种方式**不能离线、也不能添加到主屏幕**。它只适合预览。

如果 Windows 弹防火墙提示，要选「允许」。

## 方式三：打包成 APK（不推荐，但可行）

如果你确实需要 APK，最省事的路子是 Capacitor：

```bash
npm install @capacitor/core @capacitor/cli @capacitor/android
npx cap init dachu com.example.dachu --web-dir=public
npx cap add android
npx cap sync
npx cap open android      # 用 Android Studio 打 APK
```

需要装 **Android Studio + JDK**，第一次配置要一两个小时。
打出来的 APK 本质是一个 WebView 容器，功能和 PWA 完全一样。

**我的建议是跳过这一步。** 除非你要上架应用商店，或者需要访问手机硬件
（相机、蓝牙这类，现在用不到），APK 没有额外收益。

## 关于数据在手机上

- 数据存在**手机浏览器的 localStorage** 里，不上传任何服务器
- 换手机 / 清浏览器数据会丢，所以：
  - **导出文件**：设置里有「数据备份 → 导出文件」，存到网盘或发给自己
  - **分享链接**：会生成一条带数据的链接，存到备忘录，换设备打开即可恢复
- 分享链接等于你的身体数据，**别发到公开群**

## 常见问题

**Q：iPhone 和 Android 的数据能同步吗？**
不能自动同步——没有服务器，就没有账号。用「分享链接」或「导出文件」手动搬一次。

**Q：添加到主屏幕后，更新了代码会怎样？**
打开时会自动拿新版本（Service Worker 是网络优先策略处理 HTML）。
如果没变化，关掉重开一次。

**Q：会不会偷偷上传我的尺寸？**
不会。代码里没有任何对外发送数据的请求，全部计算在浏览器里完成。
你可以断网验证——断网之后所有功能都正常，这本身就说明没有联网依赖。

**Q：为什么不做成微信小程序？**
小程序需要企业主体才能上架，而且数据要过微信的服务器，
和"数据只存在本地"的目标冲突。
