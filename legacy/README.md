# 旧版单文件工具（已归档）

这三个是最早的独立单文件版本，功能已经全部整合进根目录的正式版：

| 旧文件 | 对应新位置 |
| --- | --- |
| `身体尺码档案.html` | `public/profile.html` |
| `裤子尺寸换算器.html` | `public/pants.html` |
| `大码买衣防坑手册.html` | `public/guide.html` |

保留它们只是为了对照历史版本。**正常使用请打开 `public/index.html`。**

旧版的问题（为什么重做）：

- 数据存在各页面自己的 localStorage key 里，三个工具之间不互通
- 没有导出 / 导入，清缓存就全丢
- 没有多单位切换
- 界面按桌面设计，手机上不好用
- 不是 PWA，不能离线、不能加到主屏幕
