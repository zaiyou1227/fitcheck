不会量怎么办 六个最常量错的

展开看每项的正确量法

腰围 vs 腹围：腰围量躯干最细处（通常肚脐上方）；腹围量肚脐下方肚子最凸那一圈。 大体重这两个常差 8–15cm，裤子按较大的那个买。

肩宽：左肩峰到右肩峰走直线，不要绕脖子。绕一圈叫肩围。

大腿围：站着量大腿根部最粗处，软尺水平。别坐着量，会偏大。

立裆深：坐在硬椅子上量，从你要的裤腰位置垂直量到椅面。这是唯一必须坐着量的项。

袖长两种量法：一种从肩峰到手腕骨（西式），一种从后颈中点经肩点到手腕（中式全袖长）。 两者差 9–12cm，商家不说明用哪种，你永远对不上。

实在不好量：就量一条现在穿着最舒服的裤子和上衣（平铺横量再 ×2），把这组数当目标值用， 往往比量身体更准。

③ 海淘值不值 把试错成本算成钱

海淘真实的问题不是贵，是退一次货可能比衣服还贵。 这里算的是"最后真正穿上身的那一件，相当于花了多少钱"。

这个数怎么来的

单件真实成本 =（价格 + 运费 + 退货运费 × 失败率）÷ 成功率。

意思是：你每买到一件能穿的，背后都摊上了若干次退货的运费。海淘退货运费高， 所以只要成功率不到七八成，真实成本就会翻倍——这时候同样的钱在淘宝买三件试，反而更便宜。

④ 三条渠道常识 不用背品牌

欧美码 vs 中国码同标号大 1–2 码
美码 L 的胸围≈ 100–107cm
海淘退货窗口通常 14–30 天

所以：只比围度，不比码数。下单前先确认"能不能只退不退运费"、 以及转运仓有没有退货服务——没有的话，退货运费会极其难看。

最容易踩的坑：转运公司大多不帮你退货。要么选支持直邮退货的店， 要么先用转运仓的"境内退货"服务，否则那件不合身的衣服只能烂在手里。
把这套跑顺的完整流程
  1. 先用尺码档案量出固定数字，导出一次备份。
  2. 搜「风格 + 版型 + 面料」三个词，进店先看有没有平铺尺寸表——没有的直接关掉。
  3. 用上面 9 条给这家店打分。9 分以上且三条关键项全中，才开始试单。
  4. 第一次只买 1 件、带运费险。合身就把这家存下来，问老板有没有老客群， 以后直接报数字复购——这才是省时间的核心。
  5. 海淘只用在下单前算过：成功率不到 7 成，或没有境内退货渠道，就别赌。

手机连上 Wi-Fi 或流量，打开 Safari / Chrome / 夸克 / 微信内置浏览器都行，输入下面这行：

网站在手机上打不开？ 国内常见

GitHub 的域名在国内部分网络下会被限制，尤其是移动数据网络。如果你打开是 一直转圈 / 空白 / 报错，不是你操作错了，是网络到不了。

有两个办法，都**不需要**访问 GitHub：

办法一：下载离线版（推荐）
整个工具打包成一个 60KB 的 HTML 文件，完全离线，不联网也能用。 下载后用微信「文件传输助手」发到手机，用浏览器打开即可。
下载完整单文件版（848KB）
办法二：用电脑开局域网
手机和电脑连同一个 Wi-Fi，在电脑上运行仓库里的 scripts/serve-lan.ps1，会打印一个 http://192.168.x.x:4173 的地址， 手机浏览器打开就行。不需要外网。

iPhone 怎么加到桌面 Safari 浏览器

必须在 Safari 里操作。微信、QQ 里打开的页面没有这个功能。

  1. 用 Safari 打开网址

    如果是从微信里点的链接，先点右上角「···」→「在浏览器中打开」。

  2. 点屏幕底部的「分享」按钮

    就是那个方框里一个向上箭头的图标，在 Safari 底部正中间。 如果看不到底栏，先轻轻往上滑一下屏幕。

    方框 + 上箭头在底部工具栏中间偏右
    不要点「书签」是摊开的书本图标，点错会打开书签列表

  3. 在弹出的列表里往下滑，找到「添加到主屏幕」

    它在列表靠下的位置，图标是一个带加号的方框。 滑到底部还没看到？点最下面的「编辑操作」，把它加到收藏里。

常见问题 卡住先看这里

「添加到主屏幕」找不到怎么办？

先确认你是在 Safari（iPhone） 或 Chrome（Android） 里。

微信、QQ、抖音里打开的网页没有这个功能——它们用的是内置浏览器。 解决办法：点右上角「···」，选「在浏览器中打开」，然后重来一遍。

加了图标，点开是白屏？

第一次打开需要联网下载文件，等 5 秒刷新一次。

如果一直白屏：删掉图标重新添加一次。或者用浏览器打开网址， 长按页面选「刷新」。

断网还能用吗？

能，但有个前提：至少成功打开过一次。第一次打开时会把所有文件缓存到手机里， 之后就完全离线了。

验证方法：打开一次，然后开飞行模式，再点桌面图标——如果还能进去，就是缓存成功了。

换手机了，数据怎么搬？

数据不会自动同步（因为没有服务器）。去「尺码」页底部点「复制分享链接」， 或者「导出文件」，把链接/文件存到备忘录或网盘，在新手机上打开即可恢复。

分享链接等于你的身体数据，别发到公开群。

为什么不用微信小程序？

小程序需要企业主体才能上架，而且数据要经过微信的服务器， 和「数据只存在本地」的目标冲突。

要不要装 APK？

不需要。加到桌面后体验和 App 一样：全屏、有图标、能离线。 打 APK 需要自己搭 Android 构建环境，功能完全一样，但每次改代码都要重新打包。

想自己部署一份 可选

这个站点是纯静态的，代码全部开源。你可以 fork 一份部署到自己账号下， 那样地址会变成 你的用户名.github.io/fitcheck/。
